# Duck Chaos Farm

A 3D browser-based sandbox game where you control a mischievous duck causing chaos on a sunny rural farm.

Inspired by Goat Simulator and Untitled Goose Game.

## Play

Live demo: https://Duckxmeta.github.io/Duck-Chaos-Farm/

## Controls

- **WASD / Arrow Keys**: Move (hold Shift to sprint)
- **Space**: Jump / Flutter
- **E**: Grab / Fling objects
- **F**: Quack (startles animals)
- **R**: Reset position
- **Mouse**: Look around

## Objectives

Complete all 5 chaos objectives to conquer the farm!

## Tech

- React + Vite
- Three.js / React Three Fiber / Drei / Rapier
- Tailwind CSS
- Web Audio API (procedural sounds)

Built with Grok.
